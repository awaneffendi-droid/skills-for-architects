# occupancy-calculator

Calculate occupant loads (beban hunian) from explicit task measurements in square metres and applicable original-code inputs, for Indonesia starting from Permen PU 26/PRT/M/2008 and SNI 03-1746-2000. No bundled load-factor or use-group table is shipped: retrieve and cite the original table for every calculation.

See [the skill](SKILL.md) for the current procedure and [source navigation](../../corpus/sources/catalog.json) for registered originals. Source metadata is not retrieved evidence or a coverage guarantee.
